# Restaurant Promo Streaming Service

Проект реализует streaming-сервис для обработки временных промоакций ресторанов в агрегаторе доставки еды.
Сервис читает события рекламных кампаний из Kafka, фильтрует только активные предложения, обогащает поток
данными подписчиков из PostgreSQL и формирует персональные триггеры для push-уведомлений пользователям, 
у которых ресторан добавлен в избранное.

Результаты обработки записываются сразу в два target-хранилища: в Kafka — для дальнейшей отправки 
push-уведомлений, и в PostgreSQL — для последующей аналитики фидбэка по рекламным кампаниям. Обработка 
реализована на PySpark Structured Streaming с использованием `foreachBatch`, сериализации сообщений в 
JSON и кэширования датафрейма перед записью в несколько стоков.

Реализовано:
* чтение событий рекламных кампаний из Kafka в режиме streaming;
* десериализация JSON-сообщений и преобразование их в Spark DataFrame;
* фильтрация промоакций по времени действия кампании;
* загрузка справочника подписок пользователей на рестораны из PostgreSQL;
* join потоковых данных из Kafka со статичными данными из PostgreSQL по `restaurant_id`;
* формирование персональных push-триггеров для подписчиков ресторанов;
* запись результатов в PostgreSQL для дальнейшей аналитики фидбэка;
* отправка выходных JSON-сообщений в Kafka для сервиса push-уведомлений;
* использование `foreachBatch` для записи каждого микробатча в несколько target-систем;
* кэширование датафрейма перед записью в Kafka и PostgreSQL для снижения повторных вычислений.

Технологии: PySpark, Spark Structured Streaming, Apache Kafka, PostgreSQL, JDBC, Docker, Python, SQL, JSON, kcat
